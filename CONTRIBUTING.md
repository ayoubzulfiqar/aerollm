# Contributing

## Code of Conduct

By participating in this project, you agree to maintain a welcoming and inclusive environment. Please review our [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## How to Contribute

1. Fork the repository
2. Create a feature branch from `main`
3. Make your changes with clear commit messages
4. Ensure tests pass: `go test ./...`
5. Ensure build passes: `go build ./...`
6. Open a pull request with a clear description

## Development Setup

- Go 1.18+
- Git
